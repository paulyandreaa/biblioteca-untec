# 📚 Biblioteca Digital UNTEC

## 📖 Descripción
Aplicación web dinámica diseñada para modernizar la gestión de una biblioteca universitaria. Permite al personal administrar el catálogo de libros, usuarios y préstamos de manera eficiente, reemplazando los procesos manuales. 

## ️ Tecnologías Utilizadas
- **Backend:** Java EE, Servlets, JDBC
- **Frontend:** JSP, JSTL, HTML5, CSS3
- **Arquitectura:** Patrón MVC (Modelo-Vista-Controlador)
- **Servidor:** Apache Tomcat
- **Base de Datos:** MySQL / H2

## ✨ Características Principales
- Gestión completa de libros (CRUD).
- Registro y administración de usuarios.
- Sistema de préstamos y devoluciones.
- Manejo seguro de sesiones de usuario.
- Interfaz intuitiva para personal sin conocimientos técnicos.
